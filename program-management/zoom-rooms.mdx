## Rules

- **Always paste the full URL into calendar invites.** Fireflies joins by detecting the full `us02web.zoom.us/...` link. Short links block this.
- **Never use a personal Zoom room** for client sessions.
- **Sales calls** use the sales bridge only — not engagement rooms.
- **Internal meetings** use the internal bridge only.
- **Felipe's bridge** is hosted on Stephen's line. Stephen sets it up for each new Felipe engagement.
